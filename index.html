Private peer-to-peer collaborative code editor

p2p-share is a free, serverless workspace for real-time collaborative coding, private code sharing and remote pair programming directly between browsers.

Code, run and communicate in one private room

Edit code together with multi-peer synchronization, import or download source files, run JavaScript and TypeScript in the browser, inspect attributed version logs, transfer files, use group chat, and start WebRTC audio or video calls while coding.

No application data server

Documents and files remain with connected peers or in optional browser-local recovery storage. Password protection, offline editing and direct peer connections help teams collaborate without a centralized application database.
